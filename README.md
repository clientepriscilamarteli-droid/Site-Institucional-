# Martelli Care Clinic

Hero institucional em React, TypeScript, Tailwind e GSAP. O componente reaproveitável fica em src/components/ui/lumina-interactive-list.tsx, seguindo a pasta de componentes de interface usada pelo shadcn. A ordem, os textos e os enquadramentos ficam em src/components/ui/martelli-slides.ts.

Execute npm install e npm run dev para abrir a versão local. Use npm run build para gerar dist/.

As fotos ficam em public/retratos. Para trocar uma imagem, copie o original autorizado para essa pasta e ajuste photo e position no slide correspondente.

Fotos da galeria: retratos do ensaio publicado pela Revista Mensch (https://revistamensch.com.br/mulher-em-foto-priscilla-martelli-equilibrio-entre-beleza-e-bem-estar/) e quadros da apresentação da clínica publicada no Instagram da Dra. Priscilla (https://www.instagram.com/drapriscillamartelli/reel/DVjxji7EkfN/).
